# Project Images

This folder stores the sanitized evidence images used throughout the case file.

Phase 01 expects these files:

```text
phase1_01_entra_add_user_audit.png
phase1_02_log_analytics_deployment_complete.png
phase1_03_sentinel_enabled.png
phase1_04_entra_auditlogs_diagnostic_setting.png
phase1_05_sentinel_usermanagement_kql.png
```

Images are reviewed for exposed tenant details, account information, identifiers, credentials, tokens, and other unnecessary metadata before the repository is made public.
